# Progress

Круговой индикатор прогресса для мобильных web-приложений. Тестовое задание.

**Демо:** https://top4ik228-akey-ivan.github.io/Progress/

Чистые HTML, CSS и JS (ES-модули), без библиотек и сборки.

## Состояния

| Состояние | Поведение |
|---|---|
| Normal | Value 0–100 задаёт длину дуги. Начало на 12 часах, рост по часовой стрелке, при 100 кольцо замкнуто |
| Animated | Независимое от Value бесконечное вращение по часовой стрелке |
| Hidden | Блок скрыт, место под него сохраняется (панель управления не «прыгает») |

Состояния независимы: Animated и Hidden не сбрасывают Value и друг друга.

## Запуск локально

ES-модули не работают при открытии файла двойным кликом, нужен локальный сервер:

```
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Структура

```
index.html
css/
  app.css        стили страницы и раскладка (портрет / ландшафт)
  progress.css   стили компонента Progress
  field.css      поле ввода Value
  switch.css     переключатель
js/
  app.js         связывает контролы с компонентом
  progress.js    компонент Progress
  value.js       чистые функции: ограничение и проверка значения
  value-input.js поле ввода Value с валидацией
```

Компонент Progress состоит из `progress.js`, `value.js` и `progress.css`. Остальное нужно только демо-приложению.

## Использование компонента

```html
<link rel="stylesheet" href="css/progress.css">
<div id="box"></div>

<script type="module">
  import { Progress } from './js/progress.js';

  const progress = new Progress(document.querySelector('#box'), { value: 40 });
  progress.setValue(75);
  progress.setAnimated(true);
</script>
```

## API

Конструктор: `new Progress(container, { value = 0, animated = false, hidden = false })`

| Метод | Описание |
|---|---|
| `setValue(v)` | Число или строка. Значение вне 0–100 зажимается, некорректное игнорируется (предупреждение в консоли) |
| `getValue()` | Текущее значение |
| `setAnimated(on)` / `isAnimated()` | Включить или выключить вращение |
| `setHidden(on)` / `isHidden()` | Скрыть или показать блок |
| `destroy()` | Убрать блок из страницы |

Событие `progress:change` (`CustomEvent`, всплывает) отправляется при изменении значения, новое значение в `event.detail.value`.

### Настройка через CSS-переменные

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `--progress-size` | `96px` | Размер блока |
| `--progress-color` | `#005bff` | Цвет дуги |
| `--progress-track-color` | `#eaeff5` | Цвет подложки |
| `--progress-period` | `1.5s` | Период одного оборота |

## Принятые решения

- **Дуга** рисуется SVG-окружностью с `pathLength="100"`: значение 0–100 подставляется в `stroke-dasharray` напрямую.
- **Вращение** задаётся CSS-анимацией на SVG, период один оборот за 1,5 с. При выключении блок мгновенно возвращается в положение с началом дуги на 12 часах.
- **Hidden** реализован через `visibility: hidden`, чтобы раскладка не менялась.
- **Поле Value** принимает цифры и один десятичный разделитель (`.` или `,`), число не больше 100. Недопустимое нажатие просто не срабатывает. При пустом поле кольцо не меняется, при уходе с поля текст приводится к аккуратному виду.
- **Ограничение:** при Value = 100 кольцо замкнуто и одноцветно, поэтому вращение визуально незаметно. Это следствие требования ТЗ о синей дуге без дополнительных элементов.
- **Адаптация:** портрет и ландшафт через `@media (orientation: landscape)`, размер кольца через `clamp()` и `vmin`.
